Vazirmatn (SIL OFL) is downloaded by the server at first boot into this folder (see ensureFonts in server.js)
and then served locally from /fonts. To bundle it manually instead, drop these files here:
Vazirmatn-arabic-400.woff2, Vazirmatn-arabic-700.woff2, Vazirmatn-latin-400.woff2, Vazirmatn-latin-700.woff2
